# Sistema de Atendimento para Lanchonete

Sistema de gerenciamento de pedidos e atendimento ao cliente desenvolvido em **Python**, executado via terminal (CLI).

## 📋 Sobre o Projeto

Este projeto simula o funcionamento básico de um sistema de atendimento para lanchonete.  
Foi desenvolvido com o objetivo de praticar lógica de programação, estruturação de código e manipulação de dados em Python.

## 🚀 Funcionalidades

- Cadastro de produtos
- Cadastro de clientes
- Registro de pedidos
- Controle básico de atendimento
- Interface via linha de comando (terminal)

## 🛠️ Tecnologias Utilizadas

- Python
